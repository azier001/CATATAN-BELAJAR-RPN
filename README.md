## 🎯 Tujuan Repositori

- Mendokumentasikan setiap challenge dengan **penjelasan mendalam**, bukan hanya kodenya
- Menyimpan **berbagai versi solusi** (V1, V2, V3...) beserta perbandingannya
- Membangun **kebiasaan belajar** yang terstruktur dan bisa direview kapanpun
- Menjadi **referensi pribadi** saat menghadapi problem serupa di masa depan

---

## 📐 Standar Dokumentasi

Setiap challenge didokumentasikan dengan format:

```
[challenge-folder]/
├── docs/
│   ├── 01-challenge-overview_gambaran-challenge.md
│   ├── 02-problem-solving-approach_alur-berpikir.md
│   ├── 03-v1-[solusi]_[solution].md
│   ├── ...
│   └── [N]-test-cases_kasus-pengujian.md
├── README.md                       ← index & ringkasan
└── ringkasan-algoritma-semua-versi.md
```
