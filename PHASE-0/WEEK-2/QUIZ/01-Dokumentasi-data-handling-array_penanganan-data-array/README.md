## 🎯 Tujuan & Target Pembelajaran

Setelah menguasai seluruh tantangan di dalam modul ini, Anda akan mampu:

- [x] **Akses Array Multi-Level**: Menavigasi data berstruktur matriks (array 2D) dengan percaya diri.
- [x] **Immutability Principle**: Memahami bahaya mutasi data asli dan cara aman melakukan kloning dengan `[...userData]`.
- [x] **Self-Documenting Code**: Mengubah sintaks indeks yang membingungkan (`array[i][2]`) menjadi variabel yang bercerita (`birthPlace`) menggunakan **Array Destructuring**.
- [x] **Built-in Array Mastery**: Menguasai 5 method manipulasi string & array esensial dalam ekosistem JavaScript (`splice`, `split`, `sort`, `join`, `slice`).
